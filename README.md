# Eritrea Tour Guide

A tour guide website introducing Eritrea: its history, culture, and top destinations for visitors.

## Files
- index.html: Home page with a welcome message button
- about.html: About Eritrea (history and culture)
- destinations.html: Places to visit (Asmara, Massawa, Dahlak Islands, Qohaito, Filfil)
- gallery.html: Photo gallery with mouse-over effects
- contact.html: Contact page with the booking form
- css/style.css: the one stylesheet used by every page
- js/script.js: the JavaScript functions
- images/: pictures used on the site

## How to open
Download or clone this repository, then open index.html in a web browser.
