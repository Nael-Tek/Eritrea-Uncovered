# Eritrea Tour Guide

A tour guide website introducing Eritrea's best destinations history and culture

## Files
- index.html: Home page with a welcome message button
- about.html: All you need to know about Eritrea
- destinations.html: Places to visit (Asmara, Massawa, Dahlak Islands, Qohaito, Filfil)
- travel-planning.html: key information needed for travel
- contact.html: Contact page with the inquiry form
- css/style.css: the one stylesheet used by every page
- js/script.js: the JavaScript functions
- images/: pictures used on the site

## How to open
Download as a zip file or clone this repository, then open index.html in a web browser.
